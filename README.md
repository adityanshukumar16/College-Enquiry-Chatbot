# 🎓 AI College Enquiry & Student Assistant

A responsive **frontend-only college enquiry website** built with **HTML, CSS, and JavaScript**.

The current version runs entirely in the browser. **Python is planned for future development** and is not used in this version.

## Technologies
- HTML5
- CSS3
- JavaScript

## Project structure
```text
AI College Enquiry & Student Assistant/
├── index.html
├── style.css
├── script.js
└── README.md
```

## Features
- Responsive navigation and homepage
- Quick enquiry buttons for admissions, courses, fees, hostel, scholarships and examinations
- Chatbot-style interface with predefined JavaScript responses
- Courses, notices and contact sections
- Clear chat functionality
- Responsive desktop and mobile layout

> Course and contact details are sample content. Replace them with verified information for your college before publishing.

## Run locally
1. Open the folder in Visual Studio Code.
2. Install the **Live Server** extension if needed.
3. Right-click `index.html` and choose **Open with Live Server**.

You can also open `index.html` directly in your browser.

## Current flow
```text
Student → HTML → CSS → JavaScript → Predefined demo response
```
No backend or database is required for this version.

## Future development
Python may be added later to create a backend API using FastAPI or Flask. Future plans may include a database, verified college FAQs, NLP/AI responses, RAG, an admin dashboard and deployment. These features are not implemented in the current version.
